# Trip lists: the design beside the app

`beside-cover.png`: the approved mockup (`docs/design/trip/trip-lists.dc.html`, rendered at 390 by
`tools/design-render/render.mjs`, left) beside CI run 1456's `trip-lists/cover-dark-pack` (the closed Fold at 344 dp,
right), both at 2 px per dp with a faint line every 8 dp and the 16 dp gutter in cyan (`tools/design-render/beside.py`).
The data differs (the mockup's trip, the shots' invented one); the layout is what's compared.

## Checked item by item (2026-10-30)

1. The header: **matches** (the app's "Add who's going and when you leave" shows until they're set; the mockup's ⋯
   is a tap on the header in the app).
2. Bought and Packed as two small cards: **matches** since this check (were loose text over bars).
3. The tabs: **match**.
4. Obi's card: slim chips, Add all and Not now: **matches** since this check (were 48 dp tall); the chips keep a 48 dp
   touch target, so their rows sit a little further apart than the mockup's.
5. The add field with a gold Add at its end: **matches** since this check (had no button).
6. Everyone · Me · Kids as slim pills: **matches** since this check.
7. Each group a card, its name in title case, count and chevron, a faint line between rows: **matches** since this
   check (were a caps label over loose rows); each row keeps its ⋯ (editing, 26 Oct), which the mockup predates.
