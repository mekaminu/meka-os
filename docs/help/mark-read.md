what: marks a chat read in WhatsApp from Navilife's message card, using the notification's own Mark as read.
how: Tap Mark read on a chat card in Needs you. To have Done do it too, turn on "Mark read when I finish a card" under Work mode → Messages.
tip: It's off by default because WhatsApp shows blue ticks when read receipts are on.
tip: It only works while the chat's notification is still in the shade.
