# stations.csv

Name and CRS code of every UK railway station National Rail's Darwin answers for, used by the server to find the
National Rail code of the home station and change station a household types in About you (live trains).

Source: [davwheat/uk-railway-stations](https://github.com/davwheat/uk-railway-stations) (`stations.json`), originally
from [Trainline EU's stations](https://github.com/trainline-eu/stations) and the sources listed there. Attribution to
David Wheatley, Trainline EU and their sources. Licensed under the
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/); this derived file (the name and
CRS columns only, sorted) is published here under the same licence.
